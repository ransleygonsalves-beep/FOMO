# Fonts

FOMO uses two typefaces, both shipped locally as licensed TTFs:

- **DM Serif Display** — headlines / subheadlines. `DMSerifDisplay-Regular.ttf`, `DMSerifDisplay-Italic.ttf`.
- **DM Sans** — body, UI, eyebrows. Variable upright (`DMSans-VariableFont_opsz_wght.ttf`) + variable italic (`DMSans-Italic-VariableFont_opsz_wght.ttf`).

`@font-face` declarations live at the top of `colors_and_type.css`. No external CDN is used.
